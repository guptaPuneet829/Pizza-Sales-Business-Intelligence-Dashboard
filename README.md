# 🍕 Pizza-Sales-Business-Intelligence-Dashboard
End-to-end Pizza Sales BI Dashboard using PostgreSQL, Power BI with KPI, sales trend, and product performance analysis.

# 📌 Project Overview

This project is an end-to-end Business Intelligence (BI) solution developed using PostgreSQL and Power BI to analyze pizza sales data for the period 1 January 2015 – 31 December 2015.

The objective of this project is to transform raw transactional data into meaningful business insights by performing SQL-based analysis and building interactive Power BI dashboards. The dashboard enables stakeholders to monitor sales performance, identify customer purchasing trends, evaluate product performance, and support data-driven business decisions.

---

# 🎯 Business Problem

Restaurant owners need quick access to sales insights to answer questions such as:

* How much revenue has the business generated?
* Which pizzas generate the highest revenue?
* Which products perform poorly?
* What are the busiest days and months?
* Which pizza sizes and categories contribute the most to sales?
* How do customer ordering patterns change over time?

This dashboard answers these business questions through interactive visualizations and KPI tracking.

# 🔄 Project Workflow

### 1️⃣ Data Preparation

* Imported pizza sales dataset into PostgreSQL
* Validated and cleaned the data
* Structured tables for efficient analysis

### 2️⃣ SQL Analysis

Performed backend analysis by writing SQL queries to calculate:

* Total Revenue
* Total Orders
* Total Pizza Sold
* Average Order Value
* Average Pizzas per Order
* Daily Sales Trends
* Monthly Sales Trends
* Sales by Pizza Category
* Sales by Pizza Size
* Best & Worst Selling Pizzas

### 3️⃣ Power BI Dashboard

Created an interactive two-page dashboard with dynamic filters, KPIs, charts, and business insights.

## Worst Sellers
